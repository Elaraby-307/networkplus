ايه ال Subnet وتفرق ايه عن ال Network

🔹 معنى Network

  • الـ Network (الشبكة) ببساطة هي مجموعة من الأجهزة (أجهزة كمبيوتر، سيرفرات، طابعات، راوترات… إلخ) متصلة مع بعضها عن طريق أسلاك أو لاسلكي عشان تتبادل البيانات.

  • ليها عنوان رئيسي (Network Address) بيمثل الشبكة كلها.

  • مثال:
    لو عندنا شبكة عنوانها 192.168.1.0/24 → ده معناه إن الشبكة دي ممكن تحتوي على 254 جهاز (من 192.168.1.1 لحد 192.168.1.254).

🔹 معنى Subnet

  • كلمة Subnet اختصار Sub-network يعني “شبكة فرعية”.

  • ببساطة: إحنا بناخد شبكة كبيرة ونقسمها لعدة شبكات أصغر (Subnets).

  • الهدف:

    1. تنظيم الشبكة الكبيرة.

    2. تقليل البث (Broadcast traffic).

    3. زيادة الأمان (كل subnet ممكن نعزلها).

    4. استغلال أفضل للعناوين (IP Addresses).

🔹 الفرق بين Network و Subnet

NetworkSubnet
هي الشبكة الرئيسيةهي تقسيم للشبكة الرئيسية لجزء أصغر
ممكن تحتوي على آلاف الأجهزةكل Subnet تحتوي على عدد أقل من الأجهزة
عنوانها بيتحدد بالـ Network Addressعنوانها بيتحدد بالـ Subnet Address و Subnet Mask
مثال: 192.168.0.0/16مثال: 192.168.1.0/24 و 192.168.2.0/24

🔹 مكونات الـ Subnet

أي Subnet بتتكون من:

  1. Network Address → أول عنوان في الشبكة، بيمثل اسم الشبكة (ما ينفعش يتخصص لجهاز).

  2. Usable IP Addresses → العناوين اللي ممكن نوزعها على الأجهزة (PC, Server…).

  3. Broadcast Address → آخر عنوان في الشبكة، بيستخدم لإرسال رسالة لكل الأجهزة داخل الـ Subnet.

  4. Subnet Mask → هو اللي بيحدد حجم الـ Subnet وعدد الأجهزة اللي ممكن تحتويها.

🔸 مثال عملي:
الشبكة: 192.168.1.0/24

  • Network Address = 192.168.1.0

  • Usable IPs = 192.168.1.1 → 192.168.1.254

  • Broadcast Address = 192.168.1.255

  • Subnet Mask = 255.255.255.0

لو قسمناها نصين (/25):

  • Subnet 1: 192.168.1.0 → 192.168.1.127

  • Subnet 2: 192.168.1.128 → 192.168.1.255 و بنربط ال Subnets ببعض عن طريق ال Routers

الربط بين 2 LAN

لو هنربط بين 2 LAN والاتنين تبع نفس الشركه ( We مثلا ) هيبقى ناتج الربط اسمه Network عادي طيب لو الربط بين 2 LAN من شركتين مختلفين زي (We , Vodafone) iهيبقى الناتج اسمه interNetwork

و الشركه بتاعت النت اسمها ISP (Internet service provider)

يعني ايه intranet و يفرق ايه عن internet

🔹 معنى Intranet

  • الـ Intranet = “شبكة داخلية” خاصة بمؤسسة أو منظمة.

  • الهدف منها: إنها توصل أجهزة الشركة أو المؤسسة ببعضها البعض، وتتيح لهم مشاركة الملفات والموارد (زي الطابعات، قواعد البيانات، البريد الداخلي).

  • بتكون مغلقة على الموظفين أو المستخدمين المصرح لهم بس، يعني مش أي حد من برة يقدر يدخل عليها.

🔹 مكونات الـ Intranet

الـ Intranet غالبًا بيتكون من:

  1. Servers (خوادم) → لتخزين الملفات، تشغيل قواعد البيانات، تشغيل مواقع داخلية للشركة.

  2. Clients (أجهزة المستخدمين) → أجهزة الكمبيوتر / اللابتوبات اللي بيتصل بيها الموظفين.

  3. Networking devices → سويتشات، راوترات، جدران نارية (Firewalls) عشان تأمين وربط الأجهزة.

  4. Software → تطبيقات داخلية زي البريد الإلكتروني الخاص بالشركة، أنظمة الـ ERP، مواقع داخلية (زي موقع الشركة الداخلي أو بوابة الموظفين).

🔹 الفرق بين Intranet و Internet

IntranetInternet
شبكة داخلية خاصة (Private)شبكة عالمية عامة (Public)
يستخدمها موظفو الشركة أو المؤسسة فقطيستخدمها أي شخص في العالم
مؤمنة (Firewall, Authentication)أقل خصوصية، مفتوحة للجميع
أمثلة: نظام الموارد البشرية داخل الشركة، بريد داخلي، قواعد بياناتأمثلة: Google, Facebook, YouTube
بيتطلب صلاحيات أو VPN لو عايز تدخل من برةمتاح لأي شخص عنده اتصال بالإنترنت

🔸 تشبيه بسيط:

  • تخيّل إن الشركة عندها مكتبة خاصة داخلية فيها كتب وملفات للموظفين بس → ده الـ Intranet.

  • أما المكتبات العامة اللي في أي مدينة والكل يقدر يدخلها → دي الـ Internet.

✅ العلاقة بين Intranet و LAN

  • LAN (Local Area Network):
    شبكة محلية بتربط الأجهزة (كمبيوترات، طابعات…) في مكان محدود زي مكتب أو بيت.
    هي مجرد بنية تحتية (Infrastructure) بتوصل الأجهزة ببعض.

  • Intranet:
    خدمة أو شبكة خاصة مبنية فوق الـ LAN (أو WAN أحيانًا).
    يعني هي استخدام الشبكة المحلية لتوفير موارد وخدمات للموظفين (زي مواقع داخلية، بريد داخلي، قواعد بيانات).

🔹 الفرق الأساسي

  • LAN = الأسلاك + السويتشات + الراوترات اللي بتوصل الأجهزة.

  • Intranet = المحتوى والخدمات اللي الشركة بتوفرها للموظفين جوه الشبكة دي.

🔸 مثال يوضح الفكرة

  1. عندك شركة صغيرة:

    • ركبت Switch ووصلت 10 أجهزة كمبيوتر = كده عندك LAN.

  2. جبت Server جوه الشبكة، وركبت عليه موقع داخلي للموظفين عشان يشوفوا أخبار الشركة ويشاركوا ملفات = هنا عملت Intranet.

يعني نقدر نقول:
الـ Intranet مش هو الـ LAN، لكنه بيشتغل “فوق” الـ LAN.

ايه الفرق بين Extranet , Intranet

✅ أوجه التشابه

Intranet & Extranet
الاتنين شبكات خاصة (Private Networks) مش مفتوحة للعامة.
مبنيين على نفس البنية التحتية (LAN, WAN, Servers, Firewalls).
بيستخدموا نفس البروتوكولات (TCP/IP, HTTP, FTP…).
الهدف منهم هو مشاركة موارد ومعلومات.
بيتطلبوا أمان وصلاحيات دخول (Authentication, VPN).

✅ أوجه الاختلاف

IntranetExtranet
موجه للاستخدام الداخلي فقط (موظفي الشركة).موجه للاستخدام الداخلي + جهات خارجية (موردين، شركاء، عملاء).
نطاق الوصول محدود داخل الشركة.نطاق الوصول أوسع لأنه بيشمل أطراف من خارج الشركة.
الهدف: تحسين التواصل والإنتاجية داخل المؤسسة.الهدف: التعاون ومشاركة المعلومات مع شركاء خارجيين.
الأمان عالي لكن داخلي.الأمان أعلى لأن فيه وصول من خارج الشبكة (VPN, Firewalls متقدمة).

🔸 تشبيه سريع:

  • Intranet = قاعة اجتماعات داخلية للموظفين فقط.

  • Extranet = نفس القاعة لكن فيها باب مخصوص لشركاء الشركة يدخلوا ببطاقة أو تصريح خاص.

ايه ال Work Station

جهاز كومبيوتر ب امكانيات جامده للاستخدام الفردي

ايه الفرق بين ال workstation و ال server

🔹 Workstation

  • جهاز كمبيوتر فردي قوي.

  • بيستخدمه شخص واحد لتنفيذ مهام معقدة أو ثقيلة (زي التصميم، البرمجة، التحليل).

  • يركز على قوة المعالجة الرسومية (GPU) والراحة في الاستخدام.

  • غالبًا بيكون في مكاتب المهندسين، المصممين، الباحثين.

🔹 Server

  • جهاز كمبيوتر (أو نظام) بيخدم عدة مستخدمين أو أجهزة في نفس الوقت.

  • الغرض الأساسي: تقديم خدمات (زي استضافة مواقع، قواعد بيانات، بريد إلكتروني، ملفات…).

  • يركز على الأداء المستمر والاعتمادية (بيشتغل 24/7).

  • موجود في مراكز البيانات (Data Centers) أو شبكات الشركات.

  • اكتر حاجه بتميز ال server هي ال OS بيبقى اسمه Network OS , Server OS

🔹 أوجه التشابه

  1. الاتنين أجهزة كمبيوتر قوية.

  2. الاتنين فيهم مكونات قوية (CPU, RAM, Storage).

  3. ممكن يشتغلوا بأنظمة تشغيل متقدمة (Windows Server, Linux, Unix…).

🔹 أوجه الاختلاف

WorkstationServer
مخصص لشخص واحد.يخدم عدد كبير من المستخدمين أو الأجهزة.
قوي في الجرافيك والبرامج الثقيلة.قوي في المعالجة المتوازية وتوزيع المهام.
بيستخدم عادة في التصميم والبحث.بيستخدم لتقديم خدمات (مواقع، قواعد بيانات، تخزين).
ممكن يتقفل آخر اليوم.لازم يشتغل 24/7 بدون توقف.
نظام تشغيل غالبًا Windows أو Linux عادي.نظام تشغيل متخصص (Windows Server, RedHat, Ubuntu Server…).

🔸 تشبيه مبسط:

  • الـ Workstation زي مكتب مهندس مجهز بأدوات قوية عشان ينجز شغله.

  • الـ Server زي مخزن ضخم أو مركز خدمات بيخدم عدد كبير من الناس في وقت واحد.

طيب ال servers بتستخدم ف ايه او ايه ال Server Roles

🔹 File Server

  • المقصود بيه:
    السيرفر اللي وظيفته الأساسية إنه يخزن الملفات ويخليها متاحة لباقي الأجهزة على الشبكة (Clients أو Workstations).

  • بيعمل إيه؟

    1. يوفر مكان مركزي (Centralized Storage) يخزن فيه المستخدمين ملفاتهم بدل ما تكون متفرقة على كل جهاز.

    2. يسهل مشاركة الملفات بين المستخدمين (File Sharing).

    3. يوفر صلاحيات وصول (Permissions) بحيث تقدر تحدد مين يقرأ الملف، مين يعدل عليه، ومين ممنوع يوصل له أصلاً.

    4. يضمن النسخ الاحتياطي (Backup) علشان الملفات ما تضيعش لو حصل عطل.

    5. أحيانًا يوفر خصائص زي File Versioning (استرجاع نسخة قديمة من الملف).

  • بيستخدم إمتى؟

    • في الشركات أو المؤسسات علشان كل الموظفين يشتغلوا على ملفات مشتركة من مكان واحد.

    • بدل ما كل جهاز يحتفظ بنسخته من الملف (وده ممكن يعمل تضارب في النسخ)، الكل بيشتغل على نسخة مركزية.

  • مميزاته:

    • تقليل التكرار (File Duplication).

    • أمان أعلى (بفضل إدارة الصلاحيات).

    • سهولة إدارة النسخ الاحتياطية.

    • تنظيم الملفات بشكل مركزي.

  • مثال واقعي:
    تخيل شركة فيها 50 موظف. بدل ما كل واحد عنده ملف Excel على جهازه، بيتعمل Folder على السيرفر الكل يدخل عليه. مدير الفريق ممكن يدي إذن للموظفين بالـ Read فقط، ويدي إذن للسكرتارية بـ Write، وهكذا.

🔹 Print Server

  • المقصود بيه:
    هو السيرفر المسؤول عن إدارة الطابعات (Printers) في الشبكة. بدل ما كل جهاز يتوصل مباشرة بالطابعة، الطابعات كلها بتتربط بالسيرفر، وهو اللي يوزع مهام الطباعة.

  • بيعمل إيه؟

    1. إدارة الطابعات: السيرفر يعرف كل الطابعات المتوصلة بالشبكة.

    2. إدارة طوابير الطباعة (Print Queue): لو في كذا موظف بعت أمر طباعة في نفس الوقت، السيرفر يرتب الأوامر ويطبعها واحدة واحدة.

    3. توزيع الطباعة: يختار الطابعة المناسبة (أقرب طابعة للموظف أو الطابعة اللي فاضية).

    4. تطبيق الصلاحيات: يحدد مين مسموح له يطبع ومين لأ.

    5. توفير تقارير: يوضح إحصائيات زي عدد الصفحات المطبوعة لكل موظف.

  • بيستخدم إمتى؟

    • في الشركات اللي عندها عدد كبير من الموظفين وطابعات متعددة.

    • بدل ما كل طابعة تتوصل بجهاز واحد بس، السيرفر يخلي أي موظف يقدر يطبع من أي جهاز متصل بالشبكة.

  • مميزاته:

    • تقليل التكاليف (لأن الطابعات بتتشارك).

    • سهولة الإدارة (إضافة/حذف طابعة من مكان واحد).

    • التحكم في الاستخدام (منع إسراف الورق).

  • مثال واقعي:
    في بنك، الموظفين في كل طابق يطبعوا على طابعات معينة. الموظف يضغط “Print”، والسيرفر يقرر يبعته لأي طابعة متاحة.

🔹 Web Server

  • المقصود بيه:
    هو السيرفر اللي وظيفته إنه يخزن مواقع الإنترنت (Websites) ويعرضها للمستخدمين لما يطلبوها من خلال المتصفح (Browser).

  • بيعمل إيه؟

    1. استقبال الطلب (Request):
      لما تكتب رابط زي www.google.com في المتصفح، المتصفح يبعث طلب للسيرفر.

    2. معالجة الطلب:
      السيرفر يشوف إنت طالب أي صفحة (مثلاً index.html أو صفحة تسجيل الدخول).

    3. إرسال الاستجابة (Response):
      السيرفر يبعتلك الصفحة المطلوبة (HTML, CSS, JavaScript, صور، …).

    4. أحيانًا السيرفر يتعامل مع برمجيات ديناميكية زي PHP, ASP.NET, Python (Django/Flask) علشان يولد صفحة حسب بيانات معينة (زي صفحة البروفايل الخاصة بيك).

  • بيستخدم إمتى؟

    • لاستضافة (Hosting) مواقع الإنترنت أو التطبيقات (Web Applications).

    • لو الشركة عندها موقع رسمي أو بوابة للموظفين (Intranet portal).

  • مميزاته:

    • يخلي الموقع متاح على مدار 24 ساعة.

    • يسمح لعدد كبير من الزوار يوصلوا للموقع في نفس الوقت.

    • يقدر يطبق سياسات أمان (SSL, Firewalls).

  • أمثلة على Web Servers:

    • Apache HTTP Server (أشهر واحد ومفتوح المصدر).

    • Nginx (خفيف وسريع خصوصًا مع المواقع الكبيرة).

    • Microsoft IIS (Internet Information Services).

  • مثال واقعي:
    لما تفتح فيسبوك، المتصفح يبعت طلب لسيرفرات فيسبوك. السيرفر يجيب البيانات (البوستات، الصور …) ويرجعها للمتصفح علشان تتعرض عندك.

Mail Server ?

الـ Mail Server أو خادم البريد الإلكتروني هو سيرفر (خادم) مسؤوليته إرسال واستقبال وتخزين رسائل البريد الإلكتروني (Emails) بين المستخدمين عبر الإنترنت أو داخل شبكة محلية.
هو زي مكتب البريد لكن بشكل إلكتروني:

  • في مكتب البريد العادي: انت بتكتب رسالة، تديها للمكتب، وهو يوصلها للشخص التاني.

  • في البريد الإلكتروني: برنامج البريد (زي Gmail أو Outlook) يبعث الرسالة للـ Mail Server، وهو بدوره يوصلها للـ Mail Server بتاع المستلم.

🏗️ مكوّنات الـ Mail Server الأساسية

أي Mail Server بيتكون من خدمتين رئيسيتين:

  1. Outgoing Mail Server (Server الإرسال):

    • اسمه غالبًا: SMTP Server (Simple Mail Transfer Protocol).

    • وظيفته: ياخد الرسالة من جهازك أو برنامج البريد، ويوصلها لسيرفر المستلم.

  2. Incoming Mail Server (Server الاستقبال):

    • ده السيرفر اللي بيستقبل الرسائل ويحفظها للمستخدم.

    • له بروتوكولات مشهورة:

      • POP3 (Post Office Protocol v3): بينزل الرسائل من السيرفر لجهازك، وبعد كده ممكن يمسحها من السيرفر.

      • IMAP (Internet Message Access Protocol): يخليك تشوف الرسائل وانت لسه على السيرفر (مش شرط تنزلها كلها)، وبيسمح بالمزامنة بين أجهزة مختلفة (موبايل، لابتوب…).

⚙️ خطوات إرسال إيميل من جهاز لجهاز

لما ترسل إيميل مثلًا من Gmail لحساب Yahoo:

  1. تكتب الرسالة في Gmail.

  2. Gmail Client (البرنامج أو الويب) يبعتها للـ SMTP Server بتاع Gmail.

  3. سيرفر Gmail يدور على Mail Server الخاص بـ Yahoo باستخدام الـ DNS (MX Records).

  4. الرسالة تتبعت لسيرفر Yahoo.

  5. سيرفر Yahoo يخزن الرسالة على Incoming Server (POP3/IMAP).

  6. المستلم يفتح Yahoo Mail → فيشوف الرسالة.

🧰 أمثلة على Mail Servers مشهورة

  • Gmail (Google Mail Server)

  • Outlook/Hotmail (Microsoft Mail Server)

  • Yahoo Mail

  • أو شركات صغيرة بتعمل Mail Server خاص بيها باستخدام برامج زي:

    • Postfix (في لينكس)

    • Microsoft Exchange Server

📌 ملحوظة مهمة

  • الـ Mail Server نفسه ما بيشتغلش لوحده، لازم يكون مرتبط بـ:

    • DNS Records (MX Record) عشان يعرف يوجّه الرسائل.

    • Authentication (زي SMTP Auth) عشان يمنع السبام.

    • Security (زي SSL/TLS) عشان التشفير وحماية الرسائل.

🌐 Proxy Server؟

الـ Proxy Server هو خادم وسيط (Intermediate Server) بيقف بين جهازك (العميل Client) وبين الإنترنت.
بمعنى: بدل ما جهازك يتواصل مباشرة مع المواقع، بيكلم الـ Proxy، وهو اللي يروح يجيبلك البيانات من الإنترنت ويرجعها لك.

تقدر تعتبره زي:

  • المترجم: انت بتكلم واحد مش فاهم لغتك → المترجم يوصل كلامك ويرجعلك الرد.

  • الوسيط: بدل ما تروح لمحل بنفسك، تبعت واحد يجيب الحاجة لك.

⚙️ إزاي بيشتغل؟

  1. انت تكتب في المتصفح: www.example.com.

  2. الطلب (Request) يروح للـ Proxy Server بدل ما يروح للموقع مباشرة.

  3. الـ Proxy يبعته للموقع.

  4. الموقع يرد على الـ Proxy بالصفحة.

  5. الـ Proxy يوصل الرد ليك.

🏗️ أنواع الـ Proxy Server

فيه أنواع كتير، أهمهم:

  1. Forward Proxy (الأكتر شيوعًا):

    • بيقف بين المستخدم والإنترنت.

    • بيخفي هوية المستخدم أو يفلتر المحتوى.

    • مثال: مدارس أو شركات تمنع موظفينهم من الدخول لمواقع معينة.

  2. Reverse Proxy:

    • بيقف قدام السيرفر بدل المستخدم.

    • بيستقبل طلبات المستخدمين ويروّحها للسيرفرات الداخلية.

    • مفيد لتحسين الأداء (Load Balancing) وحماية السيرفرات من الهجمات.

🎯 فوائد الـ Proxy Server

  • إخفاء الهوية (Anonymity): يخلي الـ IP الحقيقي بتاعك مش باين.

  • الأمان (Security): يمنع بعض الهجمات ويعمل فلترة.

  • تسريع التصفح (Caching): يحفظ نسخ من الصفحات المشهورة، فبدل ما يجيبها من الإنترنت كل مرة، يديك النسخة المخزنة بسرعة.

  • التحكم (Control): المؤسسات ممكن تمنع أو تسمح لموظفينهم بالدخول لمواقع معينة عن طريق الـ Proxy.

📌 أمثلة عملية

  • لما تستخدم VPN → هو في الأساس نوع من أنواع البروكسي لكن مع تشفير.

  • الشركات الكبيرة بتستخدم Reverse Proxy زي Nginx أو HAProxy عشان توزع الضغط على أكتر من سيرفر.

  • مدارس أو Cyber Cafes يستخدموا Proxy عشان يمنعوا فتح فيسبوك أو يوتيوب.

يعني ايه HOST

ال host مصطلح بيتقال على اي جهاز بياخد IP

ما هو الـ IP Address؟

  • IP (Internet Protocol) Address = عنوان رقمي فريد بيتخصص لكل جهاز على الشبكة (كمبيوتر، موبايل، راوتر…).

  • زي رقم التليفون أو عنوان البيت → بيسمح للأجهزة إنها تتعرف وتتواصل مع بعضها.

2️⃣ يعني إيه IPv4؟

  • IPv4 = Internet Protocol version 4.

  • ده الإصدار الأشهر والأقدم، ولسه مستخدم بشكل واسع.

  • بيتكون من 32-bit address (32 خانة من 0 و 1).

  • بيتكتب عادةً بصيغة أربع مجموعات (octets) من أرقام عشرية مفصولة بنقط.

    • مثال: 192.168.1.15

    • كل مجموعة (octet) = 8 bits → الرقم فيها من 0 لـ 255.

    • يبقى: 8 × 4 = 32 bits.

3️⃣ تقسيم الـ IPv4: Network Address و Host Address

الـ IP بيتقسم لجزئين:

  1. Network Address

    • يحدد الشبكة اللي الجهاز تابع ليها.

    • كل الأجهزة في نفس الشبكة بيبقى عندها نفس Network Address.

  2. Host Address

    • يحدد الجهاز نفسه جوه الشبكة.

    • لازم يكون مختلف لكل جهاز في نفس الشبكة.

4️⃣ إزاي نعرف الجزء الخاص بالشبكة والجزء الخاص بالـ Host؟

هنا بيجي دور Subnet Mask 👇

Subnet Mask

  • مثال: 255.255.255.0

  • بيحدد: كام Bit من الـ IP بيتخصّص للـ Network، والباقي للـ Host.

إزاي نقرأه؟

  • كل 255 = جزء Network.

  • كل 0 = جزء Host.

🔎 مثال عملي

IP: 192.168.1.15
Subnet Mask: 255.255.255.0

  • أول 3 Octets (192.168.1) = Network Address.

  • آخر Octet (15) = Host Address.

يعني:

  • Network Address = 192.168.1.0

  • Host Address = 15 (الجهاز ده).

🔎 مثال تاني

IP: 10.20.5.100
Subnet Mask: 255.255.0.0

  • أول 2 Octets (10.20) = Network Address.

  • آخر 2 Octets (5.100) = Host Address.

يبقى:

  • Network Address = 10.20.0.0

  • Host Address = 5.100.

🖥️ إيه هو الـ MAC Address؟

  • MAC (Media Access Control) Address = عنوان فريد وثابت بيتخصص لكل كارت شبكة (Network Interface Card – NIC) في المصنع.

  • بيتكون من 48-bit (6 مجموعات) مكتوبة بالـ Hexadecimal.

    • مثال: 00:1A:2B:3C:4D:5E.

  • كل جهاز في العالم ليه MAC مختلف، زي البصمة أو رقم الشاسيه في العربية.

💡 بيتخزن في الـ Hardware نفسه (كارت الشبكة)، مش بيتغير بسهولة.

🔎 4. مثال للتوضيح

تخيل إنك ساكن في عمارة:

  • MAC Address = رقم شقتك الداخلي اللي محدد من الشركة البانية (ما بيتغيرش).

  • IP Address = العنوان البريدي اللي البريد يستخدمه عشان يوصل لك (ممكن يتغير لو انتقلت لشقة تانية).

📌 5. علاقة MAC بالـ IP

  • لما جهازك يتصل بشبكة LAN، الراوتر بيعمل ربط (Mapping) بين الـ IP Address والـ MAC Address باستخدام حاجة اسمها ARP (Address Resolution Protocol).

  • مثال:

    • IP: 192.168.1.3

    • MAC: 00:1A:2B:3C:4D:5E
