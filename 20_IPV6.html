20_IPV6

Dec 09, 20255 min read

⭐ أولًا: ليه ظهر IPv6؟

في بداية اختراع الـ IP Protocol كان في بروتوكول واحد بس، وما كانش اسمه IPv4 أو IPv6 — هو كان مجرد IP.

مع توسّع الإنترنت وزيادة عدد الأجهزة بشكل ضخم جدًا (موبايلات – لابتوبات – كاميرات – IoT …)، بدأ IP Address Space بتاع IPv4 ينفد.

رغم وجود حلول مؤقتة زي:

  • NAT (Network Address Translation)

  • Subnetting

لكن دي كانت مجرد مسكنات لأن عدد الأجهزة بيزيد أسرع بكثير من المتوقع.

فبدأت المنظمات المسؤولة عن الإنترنت (IETF) تفكر في حل جذري → وظهر IPv6.

بعد ظهور IPv6، تمت إعادة تسمية البروتوكول القديم إلى IPv4.

⭐ مقارنة بين IPv4 و IPv6

✔ 1. حجم العنوان (Address Size)

النوععدد البتعدد العناوين
IPv432-bitحوالي 4.3 مليار عنوان
IPv6128-bitحوالي 3.4 × 10³⁸ عنوان

IPv6 عدد عناوينه ضخم جدًا لدرجة إن البشر مش ممكن يستنفذوه.

✔ 2. شكل كتابة العنوان

IPv4 Format

  • 4 Octets (كل واحد 8-bit)

  • مكتوب بـ Decimal
    مثال:
    192.168.1.2

IPv6 Format

  • 8 Blocks = quartets

  • كل Block = 16-bit

  • مكتوبة بـ Hexadecimal
    مثال:
    2001:0db8:0000:0000:0000:ff00:0042:8329

🌟 IPv6 Address Shortening Rules (اختصار العناوين)

في IPv6 عندك قاعدتين فقط للاختصار:

📌 Rule 1 — حذف الصفر من البداية (Leading Zero Omission)

0234 → 234

00ab → ab

0040 → 40

لكن لا تحذف الصفر لو في النهاية:

4500 ≠ 45 (❌ غلط)

📌 Rule 2 — استبدال أي مجموعة أصفار متكررة بـ ::

2001:0db8:0000:0000:0000:ff00:0042:8329 → 2001:db8::ff00:42:8329

⚠ مسموح باستخدام :: مرة واحدة فقط

⭐ مصطلحات جديدة في IPv6

✔ 1. Link

هي الـ Network الصغيرة المتصلة مع بعضها مباشرة.

✔ 2. Interface

هو اتصال الجهاز بالـ Link سواء:

  • Physical (كيبل / Wifi)

  • Logical (Virtual)

⭐ أنواع العناوين في IPv6 (Address Types)

🔹 1. Unicast Address

عنوان رايح لجهاز واحد فقط (Single Host).

وينقسم لنوعين:

a) Global Unicast Address

  • زي Public IP في IPv4

  • يستخدم للإنترنت

  • غالبًا يبدأ بـ:
    3/::2000

b) Link-Local Address

  • مثل APIPA في IPv4

  • يستخدم داخل الشبكة المحلية فقط

  • يبدأ دائمًا بـ:
    fe80::/10

🔹 2. Multicast Address

باكيت واحدة تروح لمجموعة Devices.

🔹 3. Anycast Address

يرسل للـ Closest Device في المجموعة (مش للكل).

Special IPv6 Addresses (عناوين خاصة ومهمة جدًا)

في IPv6 في عناوين خاصة “محجوزة” لها وظائف محددة:

1. Loopback Address

نفس فكرة 127.0.0.1 في IPv4

‘128/::1`

2. Unspecified Address

يعني “عنوان مش معروف”
زي 0.0.0.0 في IPv4

128/::

يستخدم أثناء ال DHCPv6 أو NDP قبل ما الجهاز ياخد IP.

3. Default Route

الراوتر الافتراضي:

0/::

زي 0.0.0.0/0 في IPv4.

4. Documentation Range

مخصص للأمثلة والشرح فقط:

2001:db8::/32

🌟 7) Understanding IPv6 Prefixes Clearly

IPv6 prefixes مهمة جدًا، ودي أشهرها:

PrefixMeaning
2000::/3Global Unicast (Internet)
fe80::/10Link-Local
fc00::/7Unique Local (Private)
ff00::/8Multicast
1::/128Loopback
::/128Unspecified
::/0Default Route

🌟 8) SLAAC – Stateless Address Auto Configuration

SLAAC = الجهاز ياخد IPv6 address من نفسه بدون DHCP.

إزاي؟
يستلم الراوتر prefix مثل:

2001:db8:abcd::/64

وبعدها الجهاز يعمل:

Address = Prefix + Interface ID

Interface ID ممكن يتولد من:

  • MAC address (EUI-64)

  • Randomized ID (Privacy Extensions)

🌟 9) DHCPv6 – طريقة أخرى للحصول على IP

IPv6 مش بيعتمد على DHCP زي IPv4

DHCPv6 له 3 modes:

  1. Stateless DHCPv6
    الجهاز ياخد IP من SLAAC
    وياخد DNS فقط من DHCPv6

  2. Stateful DHCPv6
    زي DHCP في IPv4
    ياخد IP + DNS + Options

  3. No DHCPv6
    يعتمد بالكامل على SLAAC

🌟 10) Neighbor Discovery Protocol (NDP)

NDP هو البديل لـ ARP في IPv4
ويعمل فقط بالـ ICMPv6

وظيفته:

  • يكتشف الجيران

  • يحدد MAC address

  • يعمل Duplicate Address Detection

  • يعرف الراوترات اللي حوالينك

ويستخدم 5 رسائل:

  1. NS — Neighbor Solicitation

  2. NA — Neighbor Advertisement

  3. RS — Router Solicitation

  4. RA — Router Advertisement

  5. Redirect (لو فيه path أقصر)

🌟 11) ICMPv6 (مهم جدًا)

ICMPv6 هو الأساس في IPv6 وبدونه البروتوكول “ميشتغلش”.

المهام:

  • Neighbor Discovery

  • SLAAC

  • Error Messages

  • Router Discovery

ومحتوى RA/RS يحدد:

  • هل نستخدم DHCPv6؟

  • هل نستخدم SLAAC؟

  • هل الجهاز يولد interface ID بنفسه؟

🌟 12) مقارنة IPv4 vs IPv6 (الملخص النهائي)

FeatureIPv4IPv6
Address Size32-bit128-bit
Address Count4.3 مليارلا نهائي تقريبًا
NotationDecimalHexadecimal
Broadcastموجودغير موجود
NATشائعغير مطلوب
DHCPأساسياختياري
ARPموجودتم إلغاؤه
SecurityOptionalBuilt-in (IPsec)
Auto Configضعيفقوي (SLAAC)
HeaderComplexSimple

🌟 13) Exam-style Summary (سهل للحفظ)

  • IPv6 يستخدم 128-bit

  • يبدأ Global Unicast بـ 2000::/3

  • Link-Local يبدأ بـ fe80::/10

  • Private IPv6 هو fc00::/7

  • Multicast هو ff00::/8

  • مفيش Broadcast

  • فيه Anycast

  • SLAAC = الراوتر يدي Prefix + الجهاز يولد Interface ID

  • ARP اتلغى → استبدل بـ NDP

  • Default Route في IPv6 = ::/0

  • Loopback = ::1

  • Unspecified = ::

  • Prefix الشائع هو 64/

  • اختصار IPv6:

    • شيل leading zeros

    • استخدم :: مرة واحدة

✅ أنواع الـ Tunneling بين IPv4 و IPv6

فكرة الـ Tunneling ببساطة:

إنك “تغلف” Traffic من IPv6 جوا IPv4 packet (أو العكس) علشان يعدّي في شبكة مش بتدعم البروتوكول الأصلي.

الفائدة:
تسمح للأجهزة و الشبكات اللي بتشتغل IPv6 إنها تتواصل فوق شبكة IPv4.

🎯 الأنواع الأساسية للـ Tunneling

1️⃣ Manual Tunneling (Static Tunnel)

⭕ أبسط وأقدم نوع
⭕ ال admin بيحدّد إيدويًا الـ tunnel endpoints (العناوين في الطرفين).

Characteristics

  • Requires manual configuration.

  • Fixed IPv4 endpoints.

  • No automatic detection.

  • Useful for lab environments أو small networks.

Example:

Router A IPv6 -> encapsulated in IPv4 -> Router B

Pros:

✔ Stable
✔ Secure
✔ Easy to understand

Cons:

❌ Not scalable
❌ Needs manual work

2️⃣ Automatic Tunneling

هنا العناوين بتتولّد أوتوماتيك باستخدام IPv4 address.

الأنواع المشهورة:

6to4 Tunneling

أشهر نوع automatic tunneling، prefix ثابت:

Prefix:

2002::/16

كيف يشتغل؟

بيستخدم IPv4 address ويحوّله داخل الـ IPv6 address automatically.

Example IPv4:

192.168.1.10

Convert to Hex:

C0A8:010A

Final IPv6 6to4 address:

2002:C0A8:010A::/48

Pros:

✔ Auto configuration
✔ Works over Internet

Cons:

❌ Not reliable اليوم
❌ Deprecated

ISATAP (Intra-Site Automatic Tunnel Addressing Protocol)

يستخدم لما تكون عندك LAN IPv4 وعايز أجهزة IPv6 تشتغل فوقها.

الشكل:

<IPv6 Prefix>::0:5EFE:<IPv4 address>

Example:

FE80::5EFE:192.168.1.10

Pros:

✔ Great for enterprise internal networks
✔ Automatic host configuration

Cons:

❌ Rarely used now
❌ Needs ISATAP router

2C️ Teredo Tunneling

Designed to allow IPv6 connectivity behind NAT.

Characteristics:

  • Works through NAT (unique feature)

  • Uses UDP port 3544

  • Not recommended for enterprises

Pros:

✔ Works even behind NAT
✔ Useful for home users

Cons:

❌ Slow
❌ High overhead
❌ Deprecated now
