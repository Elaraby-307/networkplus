Static vs Dynamic Routing

وعايز ابعت من جهاز في نيتورك A ل جهاز في نيتورك D طيب ما كدا R1 هيستقبل بس هو ميعرفش حاجه عن نيتورك D ال Routing table معندهوش معلومات لما يكون في IP في النيتورك D المفروض هيعمل ايه

characteristics for each routing protocol

في الاول هو ايه اصلا ال routing protocol هو طريقه بنستخدمها عشان نعرف الراوتر معلومات عن ال routing اللي بيقوم بيها ال Neighbor routers وكل طريقه بتفرق عن التانيه في بعض ال characteristics و اشهر ال characteristics

Scope

دا بيبقى اقصى مدى مسموحلي اعمل sharing للراوتر مع ال neighbor routers يعني لو عندي two private networks (two autonomous systems) و متصلين بالانترنت ف اهم ال routing protocols في الحاله دي هي IGP (Interior Gateway protocol) و دا اللي مستخدم داخل ال autonomous system و EGP (Exterior Gateway Protocol) دا مستخدم في الراوترز اللي في شبكه ال Internet

Metric

دي assigned value to the router فايدتها بتحدد المسافه او ال cost اللي الراوتر هيتحمله عشان يوصل لل target network

و خلي بالك كل ما القيمه دي قلت كل ما كان احسن

في طرق اقدر احسب بيها الMetric وهي

Hop Count

ودا عدد الاجهزه اللي بتعمل routing اللي بعدي عليهم وانا رايح للdestination وكل ما ال hop count قل كل ما كان ال path احسن

Bandwidth-Delay

دا التاخير اللي هيلاقيه ال Packet وهو بيعدي في السلك رايح لل destination وكل ما سرعه النقل كانت اسرع كل ما التاخير كان اقل كل ما ال path كان احسن

Relative == Link Cost

ودا قيمه ال Metric بتعتمد على ال administrator هو اللي بيحطها

Sharing Method

دي الطريقه اللي بيستخدمها الراوتر عشان ي share ال routing data مع ال neighbor routers و منها

Distance Vector

و هي بتتم كلاتي كل راوتر بيشارك ال Entire routing table بتاعه لل neighbor routers و ال neighbor router ياخد اللي ناقص عنده و يزود عدد ال hops بمقدار 1 كل راوتر بيبقى عنده direct connections مع specific number of networks و عشان هي direct في عدد ال hops هيبقى ب 0

وعمليه تبادل ال routing tables و ان كل راوتر يبقى عنده معلومات ال routing tables بتاعت ال neighbor routers دي اسمها Convergence و بتتحدث بعد فتره معينه حتى لو مفيش حاجه اتغيرت

Link State

ودي فيها تفاصيل اكتر شويتين يعني كل راوتر بيبعت ال direct connections بس مش entire routing table و بيبعتها ب LSA, LSP

🔹 LSA = Link-State Advertisement

LSA معناها “إعلان حالة الرابط”
هي الرسالة أو الإعلان اللي بيحكي عن حالة الروابط الخاصة بالراوتر.

كل راوتر بيعمل LSA بيقول فيه مثلاً:

“أنا الراوتر R1، عندي link إلى R2 بتكلفة 10، وlink إلى R3 بتكلفة 20”

الـ LSA دي بتكون زي “ورقة تعريف” عن الشبكة اللي شايفها الراوتر.

بعد كده، كل راوتر بيبعت الـ LSA دي لجيرانه، والجيران بيبعتوها لجيرانهم، وهكذا…
لحد ما كل راوتر في الشبكة يعرف كل الـ LSA’s بتاعة كل الراوترات.

🔹 LSP = Link-State Packet

LSP معناها “حزمة حالة الرابط”
وهي الرسالة اللي بتنقل الـ LSA’s من راوتر لراوتر.

يعني:

الـ LSA هو المحتوى، والـ LSP هو الظرف اللي شايله.

فممكن تقول:

  • LSA → المحتوى (الإعلان عن الروابط)

  • LSP → الرسالة أو الباكت اللي بتنقل الإعلان دا بين الراوترات

🔁 كيف بيحصل التبادل

  1. كل راوتر بيجمع معلومات عن الجيران (عن طريق Hello Packets).

  2. لما يعرف جيرانه، بيبعت LSA فيها حالته (الروابط اللي عنده + تكلفتها).

  3. الـ LSA دي بتتحط جوه LSP وبتتبعت لباقي الراوترات.

  4. كل راوتر بيخزن كل الـ LSA’s اللي استقبلها في قاعدة بيانات اسمها
    🧠 LSDB (Link-State Database).

  5. باستخدام قاعدة البيانات دي، كل راوتر بيحسب أفضل المسارات باستخدام خوارزمية Dijkstra.

كل راوتر بيبقى عنده two tables كمان غير ال routing table وهم ال neighbor table

و LSDB (link state data base) ال neighbor table بيخزن معلومات عن ال direct connection routers وال LSDB بيخزن كل حاجه عن ال neighbor routers او بمعنى اخر بيخزن رسايل ال LSA و عمليه تمرير البيانات من راوتر للتاني اسمها flooding

في ميزه في الlink state و هي ان بعد ميوصل لحاله ال convergence مش بيتحدث غير لو في حاجه تانيه اتغيرت

Hybrid

ودي من اسمها خليط هي عباره عن ال Distance Vector بس اتعمل عليها شويه تحسينات و هنعرف عنها اكتر قدام

Support VLSM (Variable Length Subnet Mask) == Subnetting

في protocols بتدعم ال subnetting وفي لا ال routing protocols اللي كانت مش بتدعم ال subnetting كان بيبقى اسمها Classful routing table دلوقتي غالبا كله بيدعم و بقى اسمهم classless routing table

Administrative distances

دا يعتبر اهم عامل وهو رقم بيمثل مدى موثوقيه البيانات اللي هتيجي من الراوترز بيتراوح من 0 - 255 كل ما كان قليل كل ماكان احسن

مثال لو عندي 3 راوترز وانا الراوتر اللي في النص جاتلي رسالتين من ال two routers اللي جنبي بتقولي انا اعرف نيتورك x ساعتها هاخد المعلومه من مين و على اساس ايه هبص على ال Administrative distances طلعوا متساويين !! ارجع لل Metric طلع بردو متساوي !!! شوف ال Load balance او مين الاتجاه الاسرع
