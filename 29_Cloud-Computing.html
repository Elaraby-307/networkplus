29_Cloud Computing

29_Cloud Computing

Dec 09, 20255 min read

1) ليه الإنترنت بيرمزوله بالسحابة (Cloud)؟

في الرسومات والمخططات (Network Diagrams) عادةً يشيروا للإنترنت برمز Cloud.
ليه؟
لإن:

  • العمليات اللي بتحصل جوّه الإنترنت مش واضحة لأي User.

  • أنت بس بتكتب URL في المتصفح (Browser)، وتدوس Enter… الموقع يفتح.

  • لكن:
    ✔ ما تعرفش الريكويست مشى في أنهي Route
    ✔ ولا كام Router عدى عليه
    ✔ ولا السيرفر موجود فين
    ✔ ولا حصل إيه بالظبط في النص

عشان كده بيسموها Cloud = ضبابية / مش باين اللي بيحصل جواها.

2) معنى Cloud بقى في الزمن الحالي

دلوقتي كلمة Cloud بقت تستخدم كتقنية كبيرة جدًا اسمها:

➡ Cloud Computing – الحوسبة السحابية

وهي مجال كبير جدًا بيتطور يوميًا والشركات كلها بتصرف عليه ميزانيات ضخمة.

3) تعريف Cloud Computing

التعريف اللي في الفيديو:
“Flexible Provision of Data Storage, Applications, and Services over the Internet”

يعني:

توفير مرن للبيانات، والتطبيقات، والخدمات الحسابية من خلال الإنترنت.

بس ده تعريف تقيل… هنفهمه بسهولة:

✔ 4) الفكرة ببساطة

بدل ما تعتمد على Local Resources عندك:
(سيرفرات – أجهزة – Storage – Backup – Security – IT Staff)

وتدفع فلوس كتير في Hardware وSoftware…

تقوم تعتمد على شركة تانية هي اللي توفر لك الكلام ده.

يعني:
بدل ما تشتري سيرفر → تستأجره من Cloud Provider.
بدل ما تعمل Backup → هم يعملوه.
بدل ما تهتم بالأمن → هم مسؤولين عنه.

وانت بس:

  • ترفع بياناتك

  • ترفع تطبيقك

  • وتدفع اشتراك بسيط

ده باختصار هو Cloud Computing.

5) الناس كتير فاهمة إن الكلاود = Google Drive

ناس كتير أول ما تسمع Cloud تقولك:

  • Dropbox

  • Google Drive

  • OneDrive

لكن الحقيقة:

✔ دي مجرد Cloud Storage Service
✔ لكن Cloud Computing أكبر وأعمق بكتير جدًا

فيها:

  • Web Servers

  • Databases

  • Application Hosting

  • Machine Learning

  • Media Streaming

  • DevOps Tools

  • Security Services

  • Networking

  • Backup

  • Load Balancing

  • Virtual Machines

  • Containers
    …وغيرها.

6) إيه هي الكلاود فعليًا؟

الكلاود = شركة (Cloud Provider)
الشركة دي:

  • تبني Data Centers ضخمة جدًا

  • فيها آلاف السيرفرات القوية

  • Storage كبيرة

  • شبكات عملاقة

  • أنظمة تبريد وأمان

  • Staff متخصصين

🔥 وهي توفر الخدمات دي للـ Clients (أفراد + شركات) مقابل فلوس.

7) أمثلة للخدمات اللي بتوفرها الكلاود

  • Web Hosting (مواقع الإنترنت)

  • Databases

  • Application Development Platforms

  • Storage

  • Media Streaming

  • Security

  • Backup

  • Virtual Machines

  • AI Tools
    … إلخ.

8) مثال مهم من الفيديو: Netflix

ناس كتير متعرفش إن:

  • منصة Netflix تعتمد بالكامل على Amazon AWS في تشغيل الفيديوهات.

  • يعني الـ Streaming اللي يجيلك على التلفزيون → جاي من Cloud Provider.

وده بيوضح قد إيه الـ Cloud بقيت جزء أساسي من خدمات العالم كله.

إيه هي أشهر خدمات الـ Cloud Computing القديمة؟

من أقدم وأشهر خدمات الكلاود:
Email Service زي Gmail أو Outlook.
طالما عندك Email Account، يبقى انت كده بتستخدم Cloud Service لأن الإيميل مش موجود على جهازك، هو متخزن على سيرفرات الشركة.

⭐ : أشهر Cloud Providers

دول الشركات الكبيرة اللي بتقدّم خدمات Cloud:

  • Amazon من خلال خدمة: AWS – Amazon Web Services

  • Microsoft من خلال: Microsoft Azure

  • Google من خلال: Google Cloud Platform – GCP

  • Alibaba من خلال: Alibaba Cloud

وفي شركات تانية زي:
IBM, Oracle, Dell, لكن الأربعة اللي فوق هما الـ Top.

⭐ أهم الـ Benefits (الفوايد) من استخدام الـ Cloud

1️⃣ Cost Saving – تقليل التكلفة

الشركات بتوفر فلوس ضخمة كانت هتصرفها على:

  • Hardware

  • Software

  • Applications

  • Backup

  • Security

  • Data Centers

الكلاود بتشيل منك كل ده.

2️⃣ On-Demand – حسب الطلب

يعني الخدمة دايمًا Available في أي وقت،
وطالب حاجة؟ بتجيلك فورًا، “كأنها تحت أمرك”.

3️⃣ Cross-Platform

الخدمات بتشتغل على أي Device:

  • Computer

  • Tablet

  • Mobile

وكمان مش فارق Operating System:

  • Windows

  • macOS

  • Linux

  • Android

  • iOS

4️⃣ Global Scale – القدرة على التوسع

في الكلاود تقدر:

  • Scale Up (تزود الموارد)

  • Scale Down (تقلل الموارد)

مثال:
أنت عندك Database واخد مساحة معينة.
كبرت فجأة؟
بضغطة زر تزود المساحة خلال ثانية واحدة بدون ورق ولا انتظار.

5️⃣ High Availability & Reliability

يعني الخدمة شغالة 24/7.

الكلاود بروفايدر بيهتموا بـ:

  • Backups

  • Disaster Recovery (لو حصلت كارثة زي حريق أو انقطاع كهربا)

  • نقل الداتا على Data Center تاني من غير ما تحسّ.

وده بيخلي الشركات تعتمد عليهم بدل ما تشيل الهم.

⭐ نروح للـ Cloud Service Models

المنظمة العالمية NIST عملت تعريف رسمي للثلاث موديلات المشهورة:

1️⃣ IaaS – Infrastructure as a Service

زي:

  • Servers

  • Storage

  • Networking

أنت بتاخد البنية التحتية جاهزة وبتبني عليها اللي انت عايزه.

2️⃣ PaaS – Platform as a Service

بتاخد Platform جاهزة للتطوير زي:

  • Databases

  • Runtime

  • Development Tools

أنت تركز في الـ Application فقط.

3️⃣ SaaS – Software as a Service

برامج جاهزة بتستخدمها أونلاين زي:

  • Gmail

  • Google Docs

  • Office 365

  • Salesforce

ده أسهل مستوى لأن كل حاجة جاهزة وانت بس بتستخدم.

⭐ قبل موديلات الكلاود: الـ On-Premises Model

ده النظام التقليدي:
الشركة هي اللي بتشتري:

  • Hardware

  • Software

  • Licenses

  • Networking Devices

  • Servers

وهي اللي:

  • بتعمل Installation

  • بتعمل Security

  • بتجيب موظفين يشغلوا الموضوع

  • وبتبني Data Center كامل على حسابها

وده مكلف جدًا.

التصنيفات التالية للـ Cloud Computing حسب الـ Deployment Models.

⭐ 1) Public Cloud – الببلك كلاود

دي الكلاود اللي أي حد يقدر يستخدمها عن طريق الإنترنت.
الشركات الكبيرة بتقدمها، زي:
AWS – Azure – Google Cloud – Alibaba Cloud

✔ مميزاتها:

  • متاحة للعامة

  • أرخص

  • مش محتاج تبني Data Center

  • مناسبة للشركات الصغيرة والمتوسطة

⭐ 2) Private Cloud – البرايفت كلاود

دي الشركات بتبنيها لنفسها فقط.
يعني الشركة تعمل:

  • Data Centers

  • Hardware

  • Software

  • Security Systems

وكل ده يكون Internally Hosted ومتاح فقط لموظفين الشركة.

✔ الشركات بتستخدمها لما:

  • الداتا Highly Sensitive

  • لازم Privacy عالية

  • مش عايزين يتعاملوا مع Public Cloud risks

⭐ 3) Hybrid Cloud – الهايبرد كلاود

ده مزيج بين Public Cloud + Private Cloud.
الشركات بتستخدم جزء برايفت وجزء ببلك.

✔ مثال:

  • الشركة عندها Sensitive Data → تخليها على Private Cloud

  • وبرامج أو سيستم عايزين يشتغلوا عليه من أي مكان → يستخدموا Public Cloud

✔ الهدف:

  • Flexibility

  • Cost Optimization

  • Security أعلى مع وجود خدمات Online جاهزة

🎯 الخلاصة المختصرة جدًا:

النوعالمعنىالاستخدام
Public Cloudمتاح لأي مستخدم عبر الإنترنتخدمات عامة – تكلفة قليلة
Private Cloudالكلاود الخاصة داخل الشركةداتا حساسة – أمان عالي
Hybrid Cloudخليط من الاثنينلما الشركة تحتاج أمان + مرونة
