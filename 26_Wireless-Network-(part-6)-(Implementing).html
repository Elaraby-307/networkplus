✅ 1. مقدمة: What is Wi-Fi Network Implementation?

بعد ما فهمنا كل أساسيات Wireless Networks (standards – security schemes – obstacles)، الوقت جه نعرف عمليًا إزاي ننفذ Wi-Fi Network على أرض الواقع.

Implementation بتبدأ من:

  • Designing Small WLANs (بيوت – مكاتب صغيرة)

  • Installing & Configuring Access Points في الشركات المتوسطة والكبيرة

✅ 2. Wireless Topologies

قبل التنفيذ لازم نفهم أنواع التوبولوجي:

A) Ad-Hoc Topology

  • كل device يتواصل directly مع device آخر

  • No Access Point

  • Peer-to-Peer network

B) Infrastructure Topology

  • الأكثر انتشارًا

  • الاتصال يكون من خلال Wireless Router / Access Point

  • كل الـ clients تتصل بالـ AP فقط

C) Mesh Topology (جديد ومهم جدًا)

  • مجموعة APs بتشتغل مع بعض كـ Peer Devices

  • في AP pairing بين الأجهزة

  • التحكم المركزي يتم بواسطة Wireless Controller

Wireless Controller

  • ممكن يكون:

    • Physical device

    • Cloud-based

    • Virtual

    • Built-in في أحد الـ APs

Benefits of Wireless Controller

  1. Centralized Authentication

  2. Load Balancing
    توزيع ال clients على APs بالتساوي

  3. Channel Management
    يمنع Overlapping Channels

  4. AP Redundancy
    لو AP وقع → يتحول الترافيك لواحد آخر تلقائيًا

  5. Rogue AP Detection
    اكتشاف أي Access Point مجهولة (هجوم Wi-Fi معروف)

✅ 3. Wireless as a Bridge Between LANs

ممكن نستخدم واي فاي كـ Point-to-Point Link بين شبكتين LAN.

  • نستخدم Directional Antenna

  • الإشارة بتتوجه في اتجاه واحد
    → يعطي مدى كبير (قد يصل لـ 300 متر)

  • كل LAN عليها AP في الطرف، ويتم الربط بينهم

✅ 4. Designing Small Wireless Networks (Small WLANs)

SOHO Router (Small Office Home Office Router)

هو Wireless Router المتواجد في البيوت والمكاتب الصغيرة.

Functions inside SOHO Router

  • Routing

  • Switching

  • DHCP

  • NAT

  • Firewall (basic)

  • USB ports for File Sharing

Router Ports & Components

  • Reset Button (Factory Reset)

  • LAN Ethernet Ports

  • WAN/Internet Port

  • USB Port

  • Power Button

  • External Antennas
    (كلما زاد العدد → better coverage)

✅ 5. Factors to Consider When Installing an Access Point

1) Range / Distance

  • AP يغطي غالبًا 70–75 meters

  • لازم أراعي حجم المكان

  • لو في مناطق ضعيفة → نستخدم:

    • Wireless Range Extender

    • Additional Access Point

2) Obstacles

أهم عائق هو:

  • Concrete Walls

  • Metal structures

  • Partitions

الحل:

  • توزيع APs في كل منطقة

  • تجنب وجود AP داخل غرفة مغلقة

3) Coverage Optimization

  • ضع الراوتر في منتصف المكان

  • في مكان مرتفع

  • Avoid corners والأماكن المخفية

4) Interference Sources

ابعد الـ AP عن:

  • Microwave ovens

  • Fluorescent lamps

  • Cordless phones

  • Bluetooth saturation

✅ 6. Designing Large Wireless Networks

في الشركات الكبيرة الموضوع أعقد، بسبب:

  • عدد كبير من الـ APs

  • Interference أعلى

  • Load كبير

  • مساحات واسعة

ولذلك بنحتاج:

🔥 Site Survey

ما هو Site Survey؟

عملية مسح للمكان قبل تركيب الشبكة لمعرفة:

  • Signal strength

  • Weak areas

  • Dead zones (Zero signal)

  • Ideal AP locations

  • Interference sources

يتم باستخدام:

Site Survey Tools / Applications

  • بنرفع خريطة المكان داخل التطبيق

  • نركّب جهاز صغير يشبه AP

  • نتحرك داخل المكان

  • البرنامج يولد Heat Map توضح:

    • Strong signal areas (بالألوان)

    • Weak signal areas

    • Dead zones

الناتج:

  • تقرير مفصل يحدد:

    • عدد الـ APs المطلوبة

    • أفضل أماكن التركيب

    • أفضل channel لكل AP

    • أماكن interference المحتمل

الشركات الكبيرة تعتمد عليه قبل أي تنفيذ.

كيفية تكوين (Configure) الراوتر اللاسلكي Wi-Fi Router

1) تجهيز البيئة قبل البدء

  • يفضَّل استخدام كمبيوتر بدل الموبايل.

  • الأفضل توصيل الكمبيوتر بالراوتر عن طريق Ethernet Cable وليس Wi-Fi.

    • عشان الإعدادات ما تقطعش لو الشبكة فصلت.

✅ 2) الدخول لصفحة إعدادات الراوتر (Router Configuration Page)

كيف تدخل لصفحة الإعدادات؟

  • افتح أي متصفح (Chrome – Edge – Firefox…)

  • اكتب في الـ Address Bar:

http://IP_address

كيف تعرف الـ IP الخاص بالراوتر؟

  • غالبًا يكون واحد من دول:

    • 192.168.1.1

    • 192.168.0.1

  • ممكن تلاقيه مكتوب:

    • على علبة الراوتر

    • على Label خلف الراوتر

    • في User Manual

  • لو مش لاقيه → اعمل search على Google باسم الشركة + موديل الراوتر.

✅ 3) تسجيل الدخول للراوتر

سيظهر مربع Login يطلب:

  • Username

  • Password

الافتراضي غالبًا:

  • admin / admin
    أو

  • admin / password

أول خطوة لازم تعملها: تغيير الـ Default Username & Password
لأن تركهم كما هم يجعل الراوتر سهل الاختراق.

✅ 4) الدخول لقسم Wireless Configuration

بعد تسجيل الدخول:

  • افتح Wireless Settings

  • هتلاقي إعدادات الشبكة (2.4 GHz) وأحيانًا (5 GHz)

🔥 5) أهم إعدادات الواي فاي التي يجب تغييرها

(1) تغيير اسم الشبكة (SSID)

  • الراوتر يأتي باسم افتراضي مثل:
    Netgear50 – TP-Link123 – D-Link

  • لازم تغييره لأسباب أمنية:

    • الاسم الافتراضي يدل إنك مبتدئ

    • يسهل على الهاكر معرفة نوع الجهاز وثغراته

    • لذلك اختَر اسمًا مخصصًا من عندك

(2) اختيار القناة (Channel)

الوضع الافتراضي:

  • أغلب الراوترات تضع Channel = Auto
    وده مناسب جدًا.

لو هتختار يدويًا (Manual):

  • على تردد 2.4GHz يوجد 13 قناة (في أمريكا 11)

  • أفضل القنوات هي:

    • 1 – 6 – 11
      (Non-Overlapping Channels)

ليه؟
عشان تمنع التداخل (Interference) مع شبكات الجيران.

(3) SSID Broadcast (إظهار أو إخفاء اسم الشبكة)

  • لو SSID Broadcast = Enabled
    → الشبكة تظهر للناس عند عمل Scan.

  • لو Disabled
    → الشبكة مخفية (Hidden Network)

⚠️ ملاحظة:
إخفاء الشبكة لا يمنع الهجمات، لكنه يزيد صعوبة الوصول للمبتدئين فقط.

(4) إعدادات الأمان (Security Settings)

هتلاقي الخيارات:

  • WEP → ضعيف جدًا → لا يُستخدم

  • WPA / WPA-PSK → قديم

  • WPA2-PSK (AES) → الأفضل حاليًا

  • WPA/WPA2 Mixed Mode
    (تستخدمه فقط لو عندك أجهزة قديمة جدًا)

معنى PSK أو Personal:

  • نفس المعنى: Pre-Shared Key

  • يعني باسورد الواي فاي العادي

لازم تختار:

✔ Security = WPA2-PSK
✔ Encryption = AES
✔ ضع باسورد قوي

(5) اختيار التردد (2.4 GHz / 5 GHz)

  • لو عايز تشغيل 5GHz:

    • فعّل إعداداته من نفس الصفحة

    • 5G أسرع، لكن مداه أقل من 2.4G

🎯 6) ملخص خطوات إعداد الراوتر بشكل صحيح

  1. الدخول للراوتر عبر:
    http://192.168.1.1

  2. تغيير Username & Password

  3. تغيير اسم الشبكة SSID

  4. اختيار القناة (أوتو أفضل – أو 1/6/11 يدويًا)

  5. تفعيل أو إلغاء SSID Broadcast حسب رغبتك

  6. اختيار:

    • Security: WPA2-PSK

    • Encryption: AES

  7. وضع باسورد قوي

  8. ضبط إعدادات 5GHz (لو متاح)
